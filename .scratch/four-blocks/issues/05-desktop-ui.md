# 05 · desktop 对话界面

**阻塞**：04。

## 要做什么

把 04 的客户端接到 mygo 的界面上，做成一个能用的对话窗口。

## 内容

- 消息流：人说的靠右，Bot 说的靠左并标名字。长消息可滚动。
- 输入框 + 发送。发送中要看得出来在发。
- 底部一行 Bot 名录，点一下在输入框里插入 `@bot_id`。
- 工单在跑时，显示「谁在干」的只读提示（来自 `tasks[]`，不据此维护状态机）。

## 验收

1. `go run .` 打开就能看到历史消息。
2. 打字发送 → 消息立刻上屏（乐观显示）→ Bot 回复到达后追加。
3. 点 Bot 名录能把 `@写手` 插进输入框。
4. 后端没起来时，界面上有一句人话说明，而不是白屏。

## 边界

不做设置页、不做日志、不做多对话切换。
