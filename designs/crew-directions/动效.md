# 动效

> 前两轮做的是**可读性**（对比度、灰阶、刻度），这一节补的是**触感**：圆角、浮起、顺滑过渡。
> 动效不进 token 文件，规范值都在本页，落地时映射到 mygo / Compose 两侧代码。
> 本文只保留**方法论**（时长曲线、60fps 原则、两侧 API、ReduceMotion）。旧色板的 token 文件与可交互原型已随草稿清理；当前色板见 [设计方向-分拣台.md](设计方向-分拣台.md) 第三节。

## 零、先说结论：框架里本来就有，项目一行没用

查证结果（2026-11-12）：

| 事实 | 证据 |
|---|---|
| `mygo v0.8.3` 自带完整动效系统 | `~/go/pkg/mod/github.com/egoist/mygo@v0.8.3/ui/motion.go`：`AnimateTo`、`Spring`、`AnimateColor`、`Keyframes`、`CubicBezier`、`InView`、`Rubberband`、`Project` |
| 有 SwiftUI 风格 spring 预设 | `motion.go:47-50`：`ui.Smooth` / `ui.Snappy`(Bounce .15) / `ui.Bouncy`(Bounce .3) |
| 内建「减少动态效果」 | `motion.go:339` 附近 `rt.preferences().ReduceMotion`：位移/尺寸/缩放瞬间到位；`NonMotion: true` 的 opacity / 颜色过渡仍播放（`motion_test.go:140` 有测试） |
| 逐帧驱动不用自己写 ticker | `AnimateTo` 内部调 `e.c.AnimationFrame()`；`ui/headless.go:64` 注明只有「drawings move」时才升帧率 |
| 有 Oklab 色彩插值 | `Animation.Oklab`，避免两种饱和色之间走过发灰的 sRGB 中点 |
| 有转场 | `ui/transition.go:162` `Transition`、`ui/content.go:45` `ContentTransition` |
| **桌面端 0 处动画调用** | `grep -rniE "animate|spring|easing|transition" desktop/*.go` 全是 `ticket`/`Frame()` 误命中 |
| **手机端 0 处动画调用** | `app/.../*.kt` 无一处 `animate*AsState` / `AnimatedVisibility` / `spring` |
| 主动重绘机制已打通 | `desktop/ui.go:359` `wake()` → `services.Invalidate()`；`:611` 数据回来 `c.Invalidate()`（修「界面停在正在读对话」时加的） |

**所以「高帧率动画」不是要引入新依赖，是把已经装好的 API 接上。** `wake()` 那条路已经证明逐帧重绘可行。

## 一、为什么之前会「素」

前两轮把九种近白面收成四种、层次全压给 `line` + 间距。对比度修对了，但**把「软」也一起删了**：

- 没有阴影 → 卡片不浮起来，第一眼是平的
- 圆角最大 16px 且同屏混用 → 没有「圆」的记忆点
- 零动效 → 所有状态变化都是硬切

修法不是加装饰，是补三样：**柔和阴影（静止时就有效） + 有语义的大圆角 + 一条共用曲线的过渡**。阴影比动画更影响第一眼的舒服感。

阴影与圆角的具体色值随旧方向作废；当前以纸张投影（1px 边 + 两层投影）与小圆角为主，见 [设计方向-分拣台.md](设计方向-分拣台.md)。

## 二、时长与曲线

**一条曲线走天下**：`cubic-bezier(.32, .72, 0, 1)` —— 出得快、收得稳、不弹过头。所有位移与淡入共用它，界面才有「同一个物理世界」的感觉。

| 档 | 时长 | 用在哪 |
|---|---|---|
| `micro` | 120–180ms | 按钮按下回弹、hover 底色、图标反馈 |
| `normal` | 280–320ms | 消息淡入、卡片浮起、页签切换、选中态 |
| `slow` | 420–480ms | 进度条、页面/栏切换、弹出层 |
| `spring` | ~500ms | `ui.Smooth`（默认，无回弹）；`ui.Snappy` Bounce .15 用于按下与头像；**`ui.Bouncy` 只用于 playful 场景，日常 UI 禁用** |

`ui.CubicBezier(0.32, 0.72, 0, 1)` 就是上面那条曲线在 mygo 里的写法。

### 60fps 的硬条件

**只动 transform / opacity。** 别动 `width` / `height` / `top` / `left` / `padding`（触发布局重算，必掉帧）。

- 阴影变化：画两层（`shadow-card` + `shadow-lift`），过渡的是上层 **opacity**，不是逐帧重算 `box-shadow`
- 进度条：`width` 是唯一例外，用合成层的 scaleX 或 `animateFloatAsState` 的 fraction
- 列表入场：stagger **30ms/条**（`Animation.Delay: time.Duration(i) * 30 * time.Millisecond`，这是 mygo 官方注释里给的写法）

## 三、桌面端落地（Go / mygo）

`AnimateTo` 是**每帧在 draw 里调用**，返回当前插值；`key` 必须稳定（同一元素同一 key 才会接着上一帧走，目标变化时保留速度，不跳变）。

```go
// 一条共用曲线（放在 theme.go 或 ui.go 常量区）
var crewEase = ui.CubicBezier(0.32, 0.72, 0, 1)

// 1. 列表 stagger 入场：位移 + 淡入，30ms 一条
fade := row.AnimateTo("enter/fade", 1, ui.Animation{
    Duration:  320 * time.Millisecond,
    Ease:      crewEase,
    Delay:     time.Duration(i) * 30 * time.Millisecond,
    NonMotion: true, // ReduceMotion 下淡入仍播放
})

// 2. hover 浮起：spring，目标变化时保留速度
lift := card.AnimateTo("hover/lift", targetLift, ui.Snappy)

// 3. 选中态底色：Oklab 插值，避免中间发灰
bg := card.AnimateColor("select/bg", p.Selected, ui.Animation{
    Duration: 240 * time.Millisecond, Ease: crewEase, Oklab: true, NonMotion: true,
})

// 4. 状态点呼吸（唯一允许的常驻循环，2.4s，NonMotion 让它可保留）
pulse := dot.Keyframes("pulse", []ui.Keyframe{
    {At: 0, Value: 0.45}, {At: 1200 * time.Millisecond, Value: 1, Ease: crewEase},
    {At: 2400 * time.Millisecond, Value: 0.45},
}, ui.KeyframeOptions{Repeat: ui.RepeatForever, Alternate: false, NonMotion: true})
```

**API 位置**（抄之前请对一眼签名）：`AnimateTo` `motion.go:319`、`Spring` `:368`、`AnimateColor` `:579`、`Keyframes` `:693`、`CubicBezier` `:839`、`InView` `:462`、`Rubberband` `:626`、`Project` `:647`、`Transition` `transition.go:162`、`ContentTransition` `content.go:45`。

**别手写 ticker**：`AnimateTo` 在值还在动时自己调 `AnimationFrame()`，静止后自动停帧。项目已有的 `wake()` / `c.Invalidate()` 是给后台数据回来用的，两者不冲突。

**减少动态**：`ui.Preferences.ReduceMotion` 由宿主偏好驱动，位移类自动瞬间到位。`NonMotion: true` 只给 opacity / color / crossfade —— 别给位移加，否则开了减少动态还在飘。

## 四、手机端落地（Kotlin / Compose）

Compose 侧目前也是 0 处动画，标准 API 直接可用：

```kotlin
private val CrewEase = CubicBezierEasing(0.32f, 0.72f, 0f, 1f)

// hover/浮起（Compose 无 hover，用于选中与按下）
val lift by animateDpAsState(
    targetValue = if (selected) (-2).dp else 0.dp,
    animationSpec = spring(
        dampingRatio = Spring.DampingRatioNoBouncy,   // 对应 ui.Smooth
        stiffness = Spring.StiffnessMedium,
    ),
    label = "lift",
)

// 消息入场
AnimatedVisibility(
    visible = shown,
    enter = fadeIn(tween(320, easing = CrewEase)) +
            slideInVertically(tween(320, easing = CrewEase)) { it / 4 },
    exit = fadeOut(tween(180, easing = CrewEase)),
)

// 进度条：动 fraction，不要动 dp 宽度
val progress by animateFloatAsState(
    targetValue = done.toFloat() / total.coerceAtLeast(1),
    animationSpec = tween(480, easing = CrewEase), label = "progress",
)
Box(Modifier.fillMaxWidth(progress).height(3.dp).background(Accent, CircleShape))
```

**关键**：位移/缩放/透明度走 `Modifier.graphicsLayer { translationY = …; scaleX = …; alpha = … }`，不要改 `Modifier.offset` / `padding` / `size`（触发 measure/layout）。阴影变化同样用双层 + alpha。

**减少动态**：读 `Settings.Global.getFloat(context.contentResolver, Settings.Global.ANIMATOR_DURATION_SCALE)`（或 `LocalContext` + 系统无障碍设置），为 0 时把 `animationSpec` 换成 `snap()`，但保留 `fadeIn`（对应 mygo 的 `NonMotion`）。

## 五、组件动效配方

| 组件 | 动什么 | 不动什么 |
|---|---|---|
| `TitleBar` | 状态文字变化 crossfade（NonMotion） | 不做位移；名字/职能是静态身份 |
| `Conversation` | 新消息从下 8px + fade，stagger 30ms | **已存在的消息不做入场**（长历史会变成瀑布，界面更吵）；无气泡正文不加动效 |
| `TaskCard` | 进度条 fraction 平滑；hover 浮起 2px + 阴影 | 卡片不弹跳；状态点呼吸仅 1 处 |
| 花名册 | hover scale 1.02 + 阴影；选中底色 Oklab 过渡 | 不做逐条弹性入场 |
| 按钮 | 按下 scale .94 → spring 回弹（180ms） | 不常驻动画 |
| 页签 / 栏切换 | glider 位移 320ms + 内容 crossfade | 不做缩放、不做翻转 |

**禁止项**：不给每条消息都做入场；不用 `ui.Bouncy`；不常驻循环动画（状态点呼吸是唯一例外）；不动布局属性；不用「加载中」的假 shimmer 冒充进度（契约要求 `empty` 与 `unavailable` 分开说）。
