这组紫色是**故意的第二套强调色**：接管画面是「你越过它动手」，和日常对话的主色绿要分得开。

## 结构要点（看过画板之后才明白的）

1. **子代理卡在消息流里**，不在右栏。表头「N 个子代理 / x 在跑 · y 已完成」+ 分隔 + 每行一个分身 + 脚注。
2. **消息气泡带尖角**：`15px 15px 4px`，右下收成 4px。
3. **代码块有逐行 +/- 高亮**：新增行绿底，删除行橙底。
4. **左栏每项有 5px 状态点**：在跑绿 / 等你赭 / 失败红 / 其余灰。
5. **右栏有「进行中 / 待你」两个标签**。
6. **手机工作区**是「看 Agent 的屏幕」：模拟器画面 + 「接手操作」「让它停一下」两个按钮。

## 还没对齐的

- 桌面端已比对：按窗口 ID 抓图（`scripts/shot-window.swift`）后与 `desktop-light.png` / `desktop-dark.png` 逐区对照，
  三栏宽度（329 / 718 / 393）、花名册卡、中栏左边距 75 均一致。唯一修过的是左栏导航行距（`Gap 2→10`）。
- 手机端已改过一轮：画板 4（对话）与画板 7（名片）基本对齐，调色板照本文抄；
  **画板 6（队伍空态）与画板 8（工作区）仍不到位**。
- 工作区那个画板（#8）后端还没有对应接口：`mobile-http.ts` 只有
  `timeline / send / work / agents / models / model / pair` 七个操作，
  缺 `GET /screen`、`POST /takeover`、`POST /pause`（现有 `settings.pause()` 是全局暂停，画板语义是单个 Bot）。
  工作区那组紫色（`#5B4BE0` / `#DCD8F7` / `#F1EFFC`）也还没进 `CrewPalette`。
